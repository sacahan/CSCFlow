# **專案需求文件**

## **專案名稱：運動中心即時人流總覽 (CSC Flow)**

以下表格詳細說明 CSC Flow 前端畫面的需求。

## **運動中心 Dashboard React 組件規格書**

### **目的**

將靜態 HTML 頁面拆解成 React 組件，提升可重用性及維護性，並方便後續開發。

---

### **組件架構**

#### **1. Layout**

##### **1.1 Sidebar**

-   **功能**: 側邊欄顯示運動中心列表，提供搜尋及選擇功能。

-   **Props**:

    -   `centers`: 運動中心列表資料。

    -   `onSelectCenter(centerName: string)`: 選擇運動中心的回調函數。

-   **子組件**:

    -   `SearchBar`: 搜尋運動中心。

    -   `CenterList`: 運動中心列表。

-   **狀態**:

    -   `isOpen`: 側邊欄是否開啟。

##### **1.2 Header**

-   **功能**: 顯示頁面標題及提供側邊欄開關按鈕。

-   **Props**:

    -   `onToggleSidebar()`: 開關側邊欄的回調函數。

##### **1.3 MainContent**

-   **功能**: 顯示主要內容區域，包括儀表板及趨勢圖。

-   **Props**:

    -   `selectedCenter`: 當前選擇的運動中心。

    -   `trendData`: 趨勢圖數據。

---

#### **2. Components**

##### **2.1 SearchBar**

-   **功能**: 提供運動中心搜尋功能。

-   **Props**:

    -   `onSearch(term: string)`: 搜尋回調函數。

##### **2.2 CenterList**

-   **功能**: 顯示運動中心列表。

-   **Props**:

    -   `centers`: 運動中心列表資料。

    -   `onSelect(centerName: string)`: 選擇運動中心的回調函數。

##### **2.3 Gauge**

-   **功能**: 顯示儀表板。

-   **Props**:

    -   `title`: 儀表板標題。

    -   `maxCapacity`: 最大容量。

    -   `value`: 當前數值。

##### **2.4 TrendChart**

-   **功能**: 顯示累積人數趨勢圖。

-   **Props**:

    -   `data`: 趨勢圖數據。

    -   `timeRange`: 時間範圍（每日、每週、每月）。

---

### **資料流**

#### **1. Props**

-   父組件將資料傳遞至子組件。

-   例如：`Sidebar` 接收 `centers` 並傳遞至 `CenterList`。

#### **2. State**

-   使用 React 的 `useState` 管理本地狀態。

-   例如：`Sidebar` 的 `isOpen` 狀態。

#### **3. 回調函數**

-   子組件透過回調函數通知父組件。

-   例如：`CenterList` 的 `onSelect` 回調函數。

---

### **樣式**

-   使用 Tailwind CSS。

-   每個組件的樣式應與靜態 HTML 保持一致。

---

### **功能需求**

#### **1. 側邊欄**

-   提供運動中心搜尋功能。

-   支援手機版及桌面版切換。

#### **2. 儀表板**

-   顯示健身房及游泳池的即時人流數據。

-   支援自適應視窗大小。

#### **3. 趨勢圖**

-   顯示每日、每週及每月的累積人數趨勢。

-   支援切換時間範圍。

---

### **技術需求**

-   **框架**: React

-   **樣式**: Tailwind CSS

-   **圖表庫**: ECharts

-   **效能要求**:
    -   首次載入時間 < 2s
    -   圖表更新延遲 < 100ms
    -   記憶體使用合理

---

### **效能考量**

#### **1. 即時數據更新**

-   **WebSocket 整合**

    -   實現即時數據更新機制
    -   斷線重連機制（重試間隔：5s）
    -   數據緩存策略（本地存儲 30 分鐘）

-   **數據處理優化**
    -   使用 `throttle` 控制更新頻率（間隔：500ms）
    -   實現數據快取機制
    -   異常數據處理策略

#### **2. 圖表效能優化**

-   **延遲載入**

    -   使用 `React.lazy` 實現圖表組件延遲載入
    -   實現預載機制，提前載入常用組件
    -   設定載入優先順序

-   **記憶體管理**
    -   組件卸載時清理 ECharts 實例
    -   定期清理過期數據
    -   大量數據分頁處理

### **錯誤處理**

#### **1. 網路錯誤**

-   **重試機制**

    -   WebSocket 斷線重連（最大重試次數：5）
    -   API 請求失敗重試（間隔：1s, 2s, 4s）
    -   錯誤日誌記錄

-   **離線支援**
    -   實現離線數據緩存
    -   使用 Service Worker 提供基本離線功能
    -   網路恢復後自動同步

#### **2. 使用者提示**

-   **錯誤提示**

    -   網路連接失敗提示
    -   數據載入錯誤提示
    -   操作失敗提示

-   **載入狀態**
    -   全局載入指示器
    -   組件級別載入狀態
    -   骨架屏幕設計
